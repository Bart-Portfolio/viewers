Drop your 10 gallery images in this folder, named exactly:

  gallery_01.jpg
  gallery_02.jpg
  ...
  gallery_10.jpg

The grid layout is:
  Odd-numbered images (01, 04, 06, 09) → landscape slots (wider)
  Even-numbered images (02, 03, 05, 07, 08, 10) → square slots

Tips:
- Landscape images look best at around 1200×800px or similar 3:2 / 16:9 ratio.
- Square images look best at 800×800px or similar.
- JPG is fine for photos. PNG also works — just update the extensions
  in index.html if you use a different format.
- Keep individual file sizes reasonable (under 500KB each) for fast
  page load. Tools like Squoosh (https://squoosh.app) make this easy
  without installing anything.
